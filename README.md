# Data Warehouse - The Ultimate Guide | Case Study

## 📌 Project Overview

This project is a **hands-on case study completed as part of the [Data Warehouse - The Ultimate Guide](https://www.udemy.com/share/106v7i3@humc71l4vTV0OjGSQwGr4IrfwsKF6KiCoeNZPlou9sO38Kq_0VVL0b4VNBJIZLUfeQ==/) course on Udemy**.

The project focuses on building a Data Warehouse solution using SQL Server Integration Services (SSIS), applying data warehousing concepts, ETL processes, and dimensional modeling to organize and prepare data for analytical purposes.

## 🎯 Project Objectives

- Understand and implement a layered Data Warehouse architecture.
- Build ETL workflows to move data between different layers.
- Apply data modeling and dimensional modeling concepts.
- Organize data into fact and dimension tables.
- Prepare structured data for reporting and analysis.

## 🏗️ Data Warehouse Architecture

The project follows a layered architecture consisting of:

- **Staging Layer:** Stores incoming data before further processing.
- **Core Layer:** Processes and organizes data for the Data Warehouse.
- **Fact and Dimension Tables:** Structure data to support analytical queries.

The implemented workflows cover product, sales, payments, and date-related data.

## 🔄 What I Applied in This Project

- **ETL Development:** Built SSIS workflows to extract, transform, and load data.
- **Data Warehouse Architecture:** Applied the Staging and Core layer approach.
- **Data Modeling:** Organized data into a structured warehouse design.
- **Dimensional Modeling:** Worked with fact and dimension tables to support data analysis.
- **Data Integration:** Processed product, sales, payment, and date-related data through the ETL pipeline.

## 🛠️ Technologies Used

- SQL Server Integration Services (SSIS)
- Microsoft SQL Server
- SQL
- ETL (Extract, Transform, Load)
- Data Warehousing
- Dimensional Modeling
